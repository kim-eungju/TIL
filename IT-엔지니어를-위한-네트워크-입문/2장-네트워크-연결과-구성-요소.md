## 1. NIC
NIC(Network Interface Card)는 흔히 랜카드라고 부르는 것
```
애플리케이션
    ↓
운영체제
    ↓
NIC
    ↓
LAN / 네트워크
```
NIC에는 보통 MAC 주소가 할당되어 있다
```
MAC Address
00:1A:2B:3C:4D:5E
```
> NIC는 컴퓨터와 네트워크 사이의 물리적 인터페이스다

---

## 2. 스위치
스위치는 여러 장비를 연결하고, MAC 주소를 보고 적절한 포트로 프레임을 전달한
```
     Switch
  ┌────┼────┐
  │    │    │
 PC1  PC2  Server
```
스위치는 통신하면서 같은 MAC Address Table을 학습한다
```
MAC 주소       Port
-------------------
AA:AA:AA       1
BB:BB:BB       2
CC:CC:CC       3
```
목적지 MAC이 테이블에 없다면?

일단 다른 포트에 전부 뿌린다. 이게 __Flooding__ 이
> L2 스위치의 핵심 = MAC 주소 기반 전달

---

## 3. 라우터
라우터는 기본적으로 IP 주소를 보고 패킷을 전달한다

라우터에는 Routing Table이 있다
```
Destination       Next Hop
10.0.0.0/8        192.168.1.1
172.16.0.0/16     192.168.1.2
0.0.0.0/0         ISP Router
```
패킷의 목적지 IP를 보고
```
목적지 IP 확인
   ↓
Routing Table 조회
   ↓
어느 경로로 보낼지 결정
   ↓
전달
```
> Router = 서로 다른 네트워크 사이의 길을 찾아주는 장비

---

## 4. 스위치와 라우터

예를 들어 내 PC가 `192.168.0.10`이고 같은 사무실 서버가 `192.168.0.20`이면

같은 네트워크니까 __스위치__ 를 통해 통신한다

```
내 PC
192.168.0.10
   │
   │ MAC 기반
   ▼
Switch
   │
   ▼
Server
192.168.0.20
```

그런데 Google 서버 같은 외부 IP로 가려면 __라우터__ 가 필요하다
```
내 PC
192.168.0.10
   │
 Switch
   │
 Router
   │
 Internet
   │
Google
```

> PC에서 흔히 보는 Default Gateway가 대개 이 외부 네트워크로 나가는 라우터의 주소다.

## 5. 방화벽

말 그대로 통신을 허용할지 차단할지 판단하는 장비/기능

```
Internet
   │
Firewall
   │
   ├── 80 허용
   ├── 443 허용
   └── 3306 차단
       │
     Server
```

---

## 6. 로드 밸런서

여러 서버에 트래픽을 분산시키는 장비/기능
```
        Client
           │
           ▼
    Load Balancer
    /      |      \
   ▼       ▼       ▼
Server1 Server2 Server3
```

사용자는 서버가 세 개인지 알 필요 없다 

하나의 주소로만 요청한다
```
api.example.com
```

---

## 7. 정리

```
      Internet
         │
      Router
   IP / Routing
         │
     Firewall
         │
  Load Balancer
         │
      Switch
  MAC / Switching
   ┌─────┼─────┐
   │     │     │
Server Server Server
   │
  NIC
```

1. NIC는 호트를 네트워크에 연결한다.
2. L2 스위치는 MAC 주소를 학습하고 MAC 테이블을 기반으로 프레임을 전달한다.
3. 목적지 MAC을 모르면 __Flooding__ 한다.
4. 라우터는 IP와 라우팅 테이블을 이용해 서로 다른 네트워크를 연결한다.
5. 방화벽은 통신을 통제하고, 로드밸런서는 트래픽을 여러 서버로 분산한다.
